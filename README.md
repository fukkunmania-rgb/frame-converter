# コマ換算

24fps固定で、アニメの秒＋コマ表記と総コマ数を相互変換するミニWebアプリ。

- `2+12Fr` → `60Fr`
- `60Fr` → `2+12Fr`
- 秒・コマは別々の数字専用欄。＋は固定表示。
- 秒・コマまたは総コマ数を編集すると、反対側へ即時反映。
- 各入力欄の右端に上下の増減ボタン。秒は1秒、コマと総コマ数は1コマずつ増減。コマの24境界では秒へ繰り上げ・繰り下げ、負の値にはしません。
- 秒・コマ欄は全角数字にも対応。総コマ数は末尾のFr・空白にも対応。
- 空欄では結果も空欄。不正な入力では説明を表示。
- データ送信・外部ライブラリなし。

`node serve.mjs`で表示されたURLを開くか、`dist/index.html`をブラウザで直接開いて使えます。
公開用ファイルは`dist/`の3ファイルです。
